# 鼠标自动小助手（macOS）

一个轻量的原生菜单栏应用。启用时会阻止显示器休眠，并提供两种工作模式：

- **防黑屏模式**：电脑空闲时，每隔一段时间把鼠标轻移 1 像素再移回来。
- **定点点击模式**：每隔一段时间点击指定位置，然后把鼠标随机移动到主屏幕内的其他安全位置。

为避免电脑长时间无法黑屏，每次运行都会启动自动停止倒计时，默认 1 小时。到期后应用会静默停止所有鼠标操作和防休眠功能。

## 使用

1. 双击 `鼠标自动小助手.app`。
2. 右上角菜单栏出现 🐭，说明正在运行。
3. 点击 🐭 可切换工作模式、暂停、调整活动间隔、立即测试或退出。

### 定点点击模式

1. 在“工作模式”中选择“定点点击后随机移动”。
2. 菜单栏会显示 3 秒倒计时；在倒计时结束前把鼠标移动到希望自动点击的位置。
3. 选择 30 秒、1 分钟、2 分钟或 5 分钟的活动间隔。
4. 可点击“现在执行一次点击”立即测试。

需要更换目标时，选择“3 秒后重设点击位置”。点击位置会保存在本机，下次启动不必重新设置。为保证自动点击正常工作，请在 macOS“系统设置 → 隐私与安全性 → 辅助功能”中允许“鼠标自动小助手”。

### 自动停止

- 菜单栏会显示当前会话的剩余时间。
- “本次自动停止”可把当前会话改为 15 分钟、30 分钟、1 小时、2 小时或 4 小时，并从修改时重新计时。
- “默认运行时长（新会话）”会保存到本机，供以后启动或重新开始时使用。
- 暂停和切换工作模式不会重置倒计时。
- 到期、锁定屏幕或屏幕进入睡眠后，会静默停止鼠标操作和防休眠功能。
- 到期后可点击“重新开始”开启一段新的默认时长会话。

如果 macOS 阻止首次打开：按住 Control 点击应用，选择“打开”；或前往“系统设置 → 隐私与安全性”确认打开。

## 重新构建

在终端进入本目录后运行：

```sh
./build.sh
```

应用完全在本机运行，不联网，也不收集任何数据。暂停或退出后会立即恢复系统原有的休眠设置。
